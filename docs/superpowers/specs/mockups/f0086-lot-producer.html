Component / pattern notes

  • Switch: no shadcn-svelte Switch exists in this repo yet. Implementation will add the bits-ui Switch wrapper to $lib/components/ui/switch/ following the shadcn-svelte recipe.
  • Filter chip: uses the existing primary-soft badge style. Chip ×-button calls the same handler that clears produces_lot from the loader query.
  • Amber warning: mirrors IndexingStatusBanner.svelte (border-l-4 border-l-amber-400 bg-amber-50). Triggered on input blur via GET /science/runs/check-lot-number.
  • Lot column: column only renders when the filter chip is active. Mono font for the value to make sequence digits scan cleanly.
  • Audit: existing log_audit() already handles diffs from PUT /runs/{id}; the audit preview card here is illustrative only — it'll surface via the existing run history view, not a new card.
