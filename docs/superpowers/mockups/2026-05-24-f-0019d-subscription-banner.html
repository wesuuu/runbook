Theming

All banners pull from theme tokens (--primary, --destructive, --border, --muted-fg). Amber states use raw Tailwind amber-* utilities to match the existing ConnectivityBanner and IndexingStatusBanner patterns. Switch palettes in the header to see lab-glass, blueprint, and apothecary.

Component reuse

CTAs ship as shadcn Button (sizes: sm, variants: default, secondary, ghost). Icons from lucide-svelte: Info, AlertTriangle, AlertCircle, CalendarX, Lock, X — same set already in the codebase.

Priority & dismissal

locked-out → cancel → trial. Only one renders at a time. Trial tiers cascade purely on days_remaining_in_trial. Dismiss key is a per-day localStorage entry — lasts the calendar day only. Cancel and lockout cannot be dismissed.
