# Document library

The **Library** is your organisation's shared collection of reference documents — SOPs, protocols, data sheets, and any other materials your team relies on. Once a document is indexed, the chat assistant can search its content and cite passages in its answers. Any team member can upload to the library; everyone in the organisation can read and search it.

## What you can do

- Upload files in PDF, DOCX, TXT, Markdown, RTF, JPEG, PNG, or HEIC format (up to 50 MB each).
- Import a document directly from a URL — Batchrite fetches the page and stores it for you.
- Search the library by keyword or meaning; results highlight the matching passages and link to the exact section.
- Ask the chat assistant a question and receive an answer cited to specific library documents.
- View the full content of any indexed document in a readable format, with a table of contents and in-document search.
- Delete documents you uploaded (if you have permission to do so).

## How to upload a document

1. In the left navigation, click **Library**.
2. Click **Upload Document** (top-right of the page). A dialog titled **Add Document** opens.
3. In the **Upload File** tab, drag a file into the drop zone or click the zone to browse for a file. Accepted types are PDF, DOCX, TXT, MD, RTF, JPEG, PNG, HEIC — maximum 50 MB.
4. A title is suggested automatically from the filename. Edit it in the **Title** field if you prefer a different name.
5. Click **Upload**. The dialog closes and your document appears in the list with a status indicator.
6. Batchrite extracts and indexes the document in the background. You can navigate away — the process continues automatically. Refresh the Library page to see the updated status.

If your document is a PDF or DOCX and the extracted text needs tidying (for example, tables or headers came out garbled), the status will show **Needs refinement**. Click **Refine** on that row to open the refinement editor, correct the text, and click **Mark refinement complete** to start indexing.

### Importing from a URL

1. Open **Add Document** as above and switch to the **Import from URL** tab.
2. Paste the URL and optionally enter a title. If you leave the title blank, Batchrite uses the page title.
3. Click **Import**. The document is fetched and processed the same way as an uploaded file.

## How to search the library

You can search the library directly or let the chat assistant do it for you.

**Direct search:**

1. Go to **Library**.
2. Type in the search bar at the top of the page (press **/** anywhere on the page to jump to it).
3. Results appear as you type, grouped by document. Each result shows the best-matching passage with keywords highlighted.
4. Click a result to open the document at that section.

**Via the chat assistant:**

Ask a product or science question in the chat panel. When the answer draws on a library document, the assistant cites the document title and the relevant passage so you can verify and read more. The assistant searches the library automatically — you do not need to navigate to Library first.
