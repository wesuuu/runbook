# Feature availability

This page summarises what Batchrite can do today and answers common
"does Batchrite support…?" questions.

## What Batchrite supports

Batchrite is a tablet-friendly Laboratory Execution System. You can:

- Organise work into projects and build reusable protocols on a visual editor.
- Execute protocols as runs, recording data step by step with a full audit trail.
- Group runs into experiments, and record deviations when you complete a run.
- Upload reference documents to the Library and search them.
- Ask the built-in Trellis AI assistant product and document questions.
- Enable GLP sign-offs, manage sites and equipment, and configure AI providers.

The other user-guide pages explain how each of these works in detail.

## Features not currently available

Some capabilities are not part of Batchrite today:

- **Voice input and dictation** — Batchrite does not currently support
  voice commands or dictation. Enter data and notes using the on-screen
  keyboard.
- **Offline mode** — Batchrite currently requires an internet connection.
  There is no offline or no-wifi mode for lab work; your device must stay
  connected while you record a run.

If your team needs one of these, let your organization administrator know.
For now, plan your work assuming a connected device and keyboard entry.
