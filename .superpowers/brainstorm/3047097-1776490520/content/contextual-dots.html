Contextual hint dots — what they look like

Small pulsing blue dots anchored next to key UI elements. Clicking one launches the tour for that context.

Example 1: Dot anchored to the editor toolbar

Save Undo Add Unit Op
A pulsing dot sits at the corner of the toolbar. First-time visitors notice it. Hovering shows "Take a tour of the protocol editor". Clicking starts the multi-step editor walkthrough.

Example 2: Dot anchored to the sidebar (unit op library)

Unit Ops
Buffer Prep
Media Prep
Seeding
Buffer Prep
Same pulsing dot, but anchored to the sidebar. When the user clicks it, a driver.js popover appears explaining "Drag unit ops from here onto the canvas to build your protocol."

Example 3: Dot on the runner page ("Start run" button)

Run: Sample Protocol · 1 of 4 steps
Start Run
On the runner page, the dot anchors to the "Start Run" button — the user's natural first click. Dismissed after first click or after the tour completes.
How it behaves:
  • Dots only appear for users who haven't completed that context's tour
  • Click the dot → multi-step driver.js tour begins, highlighting elements in sequence
  • Dismiss the tour anytime ("Skip") → dot disappears, remembered per user
  • Re-accessible from a "?" help menu if they want to replay
